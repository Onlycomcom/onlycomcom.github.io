# Onlycom

เว็บไซต์ตัวอย่างแบบ static พร้อมไฟล์ต้นฉบับที่แก้ไขต่อได้

## แก้ไขเว็บไซต์

เปิดไฟล์ `index.html` ด้วยโปรแกรมแก้ไขข้อความ เช่น Notepad หรือ VS Code แล้วแก้ข้อความ สี หรือรายละเอียดที่ต้องการ จากนั้นบันทึกไฟล์

รูปภาพแกลเลอรี `creator-01.jpeg`, `creator-02.jpeg` และ `creator-03.jpeg` อยู่ในโฟลเดอร์เดียวกับ `index.html` หากเปลี่ยนรูป ให้วางไฟล์ใหม่ในโฟลเดอร์นี้และแก้ชื่อไฟล์ใน `index.html`

## เผยแพร่

ไฟล์เว็บใช้กับบริการโฮสต์เว็บ static ได้ เมื่อแก้ไขไฟล์แล้วให้อัปโหลดหรือส่งการเปลี่ยนแปลงไปยังบริการนั้นอีกครั้ง เพื่อให้หน้าเว็บออนไลน์อัปเดตตาม

หมายเหตุ: หน้า Open แสดงแกลเลอรี 3 รูป ไม่มีระบบชำระเงิน
