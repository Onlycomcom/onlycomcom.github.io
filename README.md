# Onlycom

เว็บไซต์ตัวอย่างแบบ static พร้อมไฟล์ต้นฉบับที่แก้ไขต่อได้

## แก้ไขเว็บไซต์

เปิดไฟล์ `index.html` ด้วยโปรแกรมแก้ไขข้อความ เช่น Notepad หรือ VS Code แล้วแก้ข้อความ สี หรือรายละเอียดที่ต้องการ จากนั้นบันทึกไฟล์

## เผยแพร่

ไฟล์ `index.html` ใช้กับบริการโฮสต์เว็บ static ได้ เมื่อแก้ไขไฟล์แล้วให้อัปโหลดหรือส่งการเปลี่ยนแปลงไปยังบริการนั้นอีกครั้ง เพื่อให้หน้าเว็บออนไลน์อัปเดตตาม

หมายเหตุ: รายละเอียดบัญชีในหน้าเว็บเป็นข้อมูลตัวอย่าง และยังไม่มีระบบรับหรือตรวจสอบการชำระเงินจริง
